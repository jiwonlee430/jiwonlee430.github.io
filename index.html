CASE 1# 정답 없이 판단하고 검증스티치부티크 · 교내 축제 핸드메이드 브랜드 · 5인 팀 팀장 · 2024.03–05

품절을 판매 종료가 아니라 재생산 판단으로 바꿨습니다

데님 스크런치 약 100개 전량 판매 · 부스 전체 총매출 215만 원, 순이익 70만 원

  1. 문제

    축제 운영 2일차, 가장 반응이 좋던 데님 스크런치가 예상보다 빨리 품절됐습니다. 인기 상품이 빠지면 부스로 들어오는 손님과 다른 상품의 판매 기회까지 줄어드는 상황이었습니다.

  2. 근거

    목표 매출 150만 원에서 원가를 역산해 판매가를 정했고, 판매 전 수요조사와 선주문으로 상품별 물량을 잡아 둔 상태였습니다. 이 기준에 추가 원단 비용과 남은 판매 시간을 대 보고, 재생산해도 남는다고 판단했습니다.

  3. 실행

    팀원을 설득해 동대문에서 비슷한 데님 원단을 다시 소싱하고, 제작 공정을 난이도별로 나눠 약 30개를 추가 생산했습니다. 마지막 마무리 공정은 미리 끝내 두지 않고 부스의 포컬 포인트에 배치해, 손님 앞에서 완성하는 과정을 퍼포먼스로 보여 주며 방문을 늘리고자 했습니다. 판매 흐름에 맞춰 진열과 할인 폭을 조정했고, 마감 직전에는 묶음 구성으로 남은 재고를 정리했습니다.

  4. 달라진 것

    처음 약 70개에 추가분을 더한 약 100개를 모두 팔았습니다. 부스 전체로 총매출 215만 원, 순이익 70만 원을 남겼습니다.

CASE 2# 시키지 않았지만 시작 · 빠르게 배움수신제학원 · 아르바이트 · 2026.03–05

시험지 한 회 제작을 2~3일에서 4시간으로 줄였습니다

제작 시간 2~3일 → 4시간 · 학원 매뉴얼로 남겨 다른 근무자의 반복 작업도 줄임

  1. 문제

    시험지 한 회를 만드는 데 2~3일이 걸렸습니다. 자료 분석, 문항 작성, 해석, 검수를 매번 사람이 처음부터 반복하는 구조였습니다.

  2. 근거

    지시받은 일은 아니었습니다. 작업을 단계로 쪼개 보니 대부분이 같은 형식의 반복이었고, AI 도구로 단계별 초안을 만들고 사람은 검수에 집중하면 된다고 판단해 선생님께 먼저 제안했습니다.

  3. 실행

    Claude Code와 Codex를 자료 분석, 문항 제작, 영어 해석, 검수 역할로 나눴습니다. 단계마다 검수 지점을 두어 앞 단계 오류가 뒤로 넘어가지 않게 했고, 한 도구의 결과를 다른 도구가 교차 확인하게 했습니다. 방향이 어긋나면 바로 멈추고 프롬프트와 참조 파일을 고쳤습니다.

  4. 달라진 것

    제작 시간이 4시간으로 줄었습니다. 이 과정을 학원 매뉴얼로 남겼고, 같은 방식으로 오답 기록·타이머·TTS 기능을 갖춘 영어 듣기 시험 웹사이트도 만들었습니다.

CASE 3# 방법을 바꿔 끝까지PTKOREA · Samsung Shop App 갤럭시 언팩 · 2026.05–07

라이브 일정과 아랍어권 표시 품질을 함께 지켰습니다

라이브 전 오류 발견 · 우회안의 실제 반영까지 확인

  1. 문제

    Samsung Shop App 갤럭시 언팩 글로벌 캠페인 중, 제가 담당한 중동·북아프리카 사이트의 아랍어 페이지에서 폰트 깨짐과 오른쪽에서 왼쪽으로 읽는 RTL 카피 표시 오류를 라이브 전에 발견했습니다.

  2. 근거

    아랍어 전용 폰트가 아닌 다른 폰트로 내보내면 현지 규격과 품질 기준을 맞출 수 없었습니다. 개발팀의 단기 수정도 어려워, 수정만 기다리면 라이브 일정이 밀릴 수 있었습니다.

  3. 실행

    디자인팀과 협의해 CMS 에디터로 텍스트를 넣는 방식 대신 통이미지 에셋으로 전환하는 우회안을 제안했습니다. Jira로 인도 개발팀과 조율하고 개발콜에도 참여했습니다.

  4. 달라진 것

    우회안이 실제 페이지에 반영된 것을 다시 확인했고, 오류가 고객에게 노출되기 전에 막았습니다.

Shop App 해외 버전. 아랍어 화면은 레이아웃 전체가 오른쪽에서 왼쪽으로 뒤집힙니다.

CASE 4# 시키지 않았지만 시작밴드 동아리 한소리 · 연출부장 · 2020.07–2022.06

예산이 끊긴 동아리에 상점 스폰서십을 만들었습니다

학교 주변 상점 협찬 유치 · 신입 지원자 전년 대비 2배

  1. 문제

    코로나로 공연 예산이 끊겨, 활동을 이어가려면 약 100만 원의 대관비를 따로 마련해야 했습니다.

  2. 근거

    부원 사비로 메우는 방식은 오래가지 못한다고 봤습니다. 반대로 학교 주변 상점은 학생에게 알릴 통로가 필요했습니다. 양쪽 필요가 맞는 지점이 있었습니다.

  3. 실행

    포스터·팸플릿·SNS·유튜브에 상호와 할인 정보를 노출하는 대가로 대관비를 지원받는 구조를 만들었습니다. 상점을 찾아가 취지를 설명하고, 홍보물 샘플을 함께 확인하며 조건을 맞췄습니다. 홍보물 디자인도 맡았습니다.

  4. 달라진 것

    협찬을 유치해 공연을 이어갔고, 연출부장으로 일한 기간에 신입 지원자가 전년보다 2배 늘었습니다.

제가 디자인한 공연 포스터. 하단에 협찬 상점이 들어갑니다.

마이리얼트립에서 도전하고 싶은 과제

마이리얼트립을 예약할 때만 여는 앱에서, 여행을 준비하는 내내 여는 앱으로 넓히고 싶습니다.

제가 겪은 일

항공권과 숙소는 앱에서 예약했지만, 여행 준비는 그때부터 시작이었습니다. 예약한 비행기와 숙소를 날짜별 일정에 맞춰 넣고, 가고 싶은 곳을 동선대로 배치하고, 아직 하지 않은 예약을 챙기고, 여행 중에 쓴 돈을 정리하는 일은 모두 엑셀에서 했습니다. 2023년부터 여행마다 이런 시트를 만들어 지금까지 10개가 됐습니다.

저만 겪는 일이 아니었습니다

이 시트를 템플릿으로 정리해 블로그에 공유했더니 조회 2,541회, 댓글 186개가 달렸습니다. 예약을 마친 뒤의 준비를 손으로 하고 있는 여행자가 많다는 뜻으로 받아들였습니다.

지금의 마이리얼트립

항공부터 숙소, 투어까지 한 앱에서 예약할 수 있지만, 예약이 끝나면 앱을 열 이유가 줄어듭니다. 「내여행」에는 예약 내역과 다녀온 도시 컬렉션이 모여 있고, 예약들을 하나의 일정으로 엮는 일은 여전히 앱 밖에서 일어납니다. 여행자가 일정을 마이리얼트립 안에서 짜게 되면, 일정 사이 빈 시간에 맞는 투어나 이동편을 바로 그 자리에서 제안할 수 있습니다. 예약 플랫폼이 여행 준비의 출발점이 되는 것입니다.

입사하면 이렇게 풀어 보겠습니다

  1. 예약을 마친 고객이 출발 전에 앱 밖에서 어떤 준비를 하는지부터 확인하겠습니다.
  2. 예약한 항공과 숙소가 날짜별 일정으로 정리되고, 빈 시간과 남은 준비가 한눈에 보이는 작은 화면부터 만들어 보겠습니다.
  3. 출발 전에 앱을 다시 여는 고객이 늘었는지, 그 화면에서 이어진 추가 예약이 있는지로 결과를 확인하겠습니다.
